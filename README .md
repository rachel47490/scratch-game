# Apple Catcher

A simple interactive browser game where you control a basket, catch falling apples, and dodge rocks.

## How to Play
- Move the basket with the **left/right arrow keys** (or drag with a mouse or finger).
- Catch **apples** to score points.
- Avoid **rocks**. Each one you catch costs a life.
- The game ends when you run out of lives (you start with 3).
- Press **Enter** or tap to start and to play again.

## Features
- Three sprites: player (basket), collectible (apple), obstacle (rock)
- Keyboard and touch controls
- Live score and lives display
- Start screen and game over screen
- Items fall faster as your score grows

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser.

## Built With
HTML, CSS, and JavaScript (Canvas), managed with Git and GitHub.
